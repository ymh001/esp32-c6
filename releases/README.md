# 烧录包

目录：`<project>/v<version>/`。
合并镜像：`<project>-<chip>-v<version>-merged.bin`。
每个版本附 README，记录目标板、烧录方法、验证状态和 SHA-256。
版本包由对应源码项目导出；临时产物保留在源码项目的 `build/`。
含个人网络凭据的镜像仅供本地烧录，不提交或上传。

`desk-clock` 和 `pocket-home` 分别管理版本。本仓库当前提交的是版本说明、校验和及验证记录；含私有凭据的 BIN 已被忽略，不会出现在远端。校验和对应本地验证镜像，不代表远端提供了镜像下载。需要镜像时请进入对应源码项目，配置自己的凭据后编译和导出。
