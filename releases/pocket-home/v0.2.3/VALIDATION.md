# v0.2.3 验证记录（2026-09-27）

## 结论

SD 文件接口已实现，但当前插入卡的初始化异常，**实卡读写未通过**。
本版不能作为已完成实卡验收的发布版本。没有格式化、修复分区或覆盖用户文件。

## 已通过

- ESP-IDF 5.5.2 / ESP32-C6 构建。
- POSIX 文件测试：二进制与 UTF-8 文件读写、限制读取长度、禁止路径穿越、
  独占创建不覆盖已有文件、8 KB 自检、重名避让和清理；ASan/UBSan 检查。
- 能源数据解析、旋转绘制及 LVGL 80 次界面生命周期测试。
- 实机界面自检：30 次页面切换、四方向旋转、亮度写入；网络和 Grafana 数据有效。
- 刷机前已备份整个 16 MB Flash；验证分区表与原设备一致，仅更新 `0x20000` 应用区，
  保留 NVS、Wi-Fi 设置和原分区布局。备份及含私有配置的镜像只保存在本地。

## 实卡异常及排查

- 标准初始化在 ACMD13（SD Status）超时。
- 临时跳过该步骤后，后续 SCR 校验仍失败；降低时钟到 1 MHz 没有解决。
- 进一步诊断出现空卡名、无效容量、sector_size=1 / capacity=0；不能据此判断文件系统格式。
- 隔离测试覆盖：普通 SPI 无 DMA、普通 SPI 有 DMA、QSPI 引脚共享有 DMA，
  三种配置均复现异常；轮询传输同样未解决。
- 临时协议绕过、总线探测及链接包装全部移除；最终保留标准初始化与 CRC 校验，
  对全零/全 FF 的 CID/CSD 响应额外拒绝，防止使用无效几何信息访问文件系统。
- 等待关机重新插卡、完整重新上电后复测；如仍失败，需用另一张卡或读卡器交叉确认。

## 尚未验证

实卡 FAT 挂载、8 KB 写入关闭重开回读、卸载后重新挂载，以及 SD 读写时的屏幕稳定性。
不支持 exFAT/NTFS、USB 大容量存储或无条件热插拔。卡异常不会阻止屏幕界面启动。
